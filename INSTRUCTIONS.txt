============================================================
PROCEDURE — UPLOADER UNIQUEMENT pages/mx.html
============================================================

ETAPE 1 — Aller sur GitHub
---------------------------
https://github.com/6pri1gat/gat-conseils-voyageurs/tree/main/pages

Vous voyez le dossier pages/ avec mx.html dedans.

ETAPE 2 — Ouvrir mx.html sur GitHub
------------------------------------
Cliquer sur mx.html.

ETAPE 3 — Editer le fichier
----------------------------
Cliquer sur le crayon ✏ en haut à droite.

ETAPE 4 — Tout effacer
-----------------------
Cliquer dans la zone de code, Ctrl+A pour tout sélectionner,
puis Suppr pour effacer.

ETAPE 5 — Coller le nouveau contenu
------------------------------------
Sur votre PC, ouvrir avec le BLOC-NOTES :
GITHUB-A-UPLOADER\pages\mx.html

Faire Ctrl+A puis Ctrl+C pour copier.

Revenir sur GitHub, cliquer dans la zone vide, faire Ctrl+V.

ETAPE 6 — Sauvegarder
----------------------
Descendre tout en bas. Cliquer le bouton vert "Commit changes".

ETAPE 7 — Patienter et tester
------------------------------
Patienter 2 minutes. Ouvrir en navigation PRIVEE :
https://6pri1gat.github.io/gat-conseils-voyageurs/pages/mx.html

Vous devez voir :
  [ ] Préambule des obligations en 3 colonnes (bleu/orange/rouge)
  [ ] Tableau des vaccinations avec petits "i" gris
  [ ] Au survol d'un vaccin, popup noire avec détails
  [ ] Section 6 (Retour France) avec encadré rouge et "8 jours"
  [ ] Bouton flottant rouge "Démarches retour France →" en bas à droite

============================================================
SI LE REPO GITHUB A DES PROBLEMES
============================================================

Si vous avez des fichiers tronqués (INDEX~1, COUNTR~1, etc.) :

1. Supprimer tous les fichiers tronqués un par un (poubelle + commit)
2. Utiliser uniquement la méthode "Create new file" pour les uploads
3. Toujours coller le contenu via Ctrl+C / Ctrl+V depuis le Bloc-notes
   (jamais glisser-déposer pour éviter le bug Windows nom court)

Pour repartir de zéro proprement, uploader UN PAR UN dans cet ordre :
  1. index.html              (Create new file → coller → commit)
  2. countries.json          (Create new file → coller → commit)
  3. countries.csv           (Add file → Upload files OK car nom court)
  4. country-template.html   (Create new file → coller → commit)
  5. README.md               (Create new file → coller → commit)
  6. pages/mx.html           (Create new file, nom = "pages/mx.html"
                              avec slash pour créer le dossier)
