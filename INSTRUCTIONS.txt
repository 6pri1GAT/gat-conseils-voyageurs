PROCEDURE — REPARTIR DE ZERO PROPREMENT
============================================================

PHASE 1 — VIDER LE REPO ACTUEL
-------------------------------
Sur https://github.com/6pri1gat/gat-conseils-voyageurs

1. Cliquer sur chaque fichier UN PAR UN (sauf .git et .github)
2. Cliquer l'icône poubelle 🗑 en haut à droite
3. Cliquer "Commit changes" en bas
4. Répéter pour chaque fichier visible

Pour le dossier "pages", cliquer dedans, supprimer mx.html
puis revenir et le dossier disparaît automatiquement.

A la fin, le repo doit être VIDE (juste le README qui se
recrée automatiquement, ou alors complètement vide).

PHASE 2 — UPLOADER LES NOUVEAUX FICHIERS
-----------------------------------------
ORDRE IMPORTANT :

1. UPLOADER .nojekyll EN PREMIER (le fichier vide)

   - Sur GitHub, cliquer "Add file" → "Create new file"
   - Dans le champ nom, taper EXACTEMENT : .nojekyll
     (avec le point au début, sans extension)
   - Laisser la zone de contenu COMPLÈTEMENT VIDE
   - Descendre en bas, cliquer "Commit new file"

   ⚠ Ce fichier est CRITIQUE. Sans lui, GitHub Pages active
     Jekyll qui plante sur le JavaScript de la carte.

2. UPLOADER LES AUTRES FICHIERS

   Méthode rapide : "Add file" → "Upload files"

   Glisser-déposer ces 4 fichiers depuis votre dossier local
   GITHUB-A-UPLOADER (sans le sous-dossier pages) :
     - index.html
     - countries.json
     - countries.csv
     - country-template.html
     - README.md (optionnel mais recommandé)

   Vérifier que les noms affichés sont en MINUSCULES
   (pas INDEX~1.HTM ni autre tronqué).

   Si un nom est tronqué : annuler et utiliser
   "Create new file" + copier-coller du contenu via Bloc-notes.

   Cliquer "Commit changes" en bas.

3. UPLOADER pages/mx.html

   - Cliquer "Add file" → "Create new file"
   - Dans le champ nom, taper EXACTEMENT : pages/mx.html
     (avec le slash pour créer le dossier)
   - Sur votre PC, ouvrir GITHUB-A-UPLOADER\pages\mx.html
     avec le BLOC-NOTES (clic droit → Ouvrir avec → Bloc-notes)
   - Ctrl+A puis Ctrl+C pour copier
   - Revenir sur GitHub, coller dans la zone vide avec Ctrl+V
   - Vérifier que la dernière ligne est </html>
   - Cliquer "Commit new file"

PHASE 3 — VERIFIER LE DEPLOIEMENT
----------------------------------
1. Aller sur :
   https://github.com/6pri1gat/gat-conseils-voyageurs/actions

2. Attendre que le dernier workflow ait un ROND VERT ✅
   (peut prendre 1 à 5 minutes en heures normales)

   Si le workflow timeout après 15 min ("Cancelled after 15m") :
   GitHub a une file d'attente surchargée.
   Solutions :
     a) Réessayer plus tard (heures creuses, soir, week-end)
     b) Retenter en faisant un mini-commit
        (modifier README.md → ajouter un espace → commit)
     c) Si ça persiste, utiliser SharePoint à la place
        (voir les autres méthodes proposées)
