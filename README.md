# gat-conseils-voyageurs

Site interactif des conseils aux voyageurs GAT International — carte mondiale et niveaux de vigilance.

## Fonctionnalités

- **Carte mondiale interactive** (D3 + Natural Earth) : zoom, panoramique, 195 pays cliquables
- **4 niveaux de vigilance** France Diplomatie : normale, vigilance renforcée, déconseillé, formellement déconseillé
- **Pages pays** : préambule des obligations en 3 phases (avant / pendant / après mission)
- **Popups vaccinales** au survol avec règles détaillées (schéma, rappels, durée)
- **Section Retour France** mise en évidence (CPAM 8 jours, fiscalité, restitutions GAT)

## Sources

France Diplomatie (MEAE), Europ Assistance, AXA Assistance, Institut Pasteur, Calendrier vaccinal Santé Publique France 2024, Ameli.fr.
