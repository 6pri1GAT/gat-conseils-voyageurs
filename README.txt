DOSSIER À UPLOADER SUR GITHUB
==============================

Ce dossier contient UNIQUEMENT les fichiers à mettre en ligne sur GitHub Pages
(donc visibles publiquement sur internet).

Fichiers présents :
- index.html             : page d'accueil avec carte mondiale interactive
- country-template.html  : modèle vierge de page pays (sans contenu sensible)
- countries.json         : base de données des 195 pays (lue par la carte)
- countries.csv          : même base au format Excel (pour suivi)

Fichiers VOLONTAIREMENT EXCLUS car contiennent des données internes :
- pages/mx.html              (page Mexique avec procédures internes)
- contacts-gat.html          (annuaire interne GAT)
- contacts-gat.json          (numéros directs internes)
- *.md                       (procédures internes)
- generate_countries.py      (script technique non utile en ligne)

Ces fichiers exclus restent uniquement dans votre SharePoint interne.

Voir GUIDE-GITHUB-PAS-A-PAS.md pour les instructions de déploiement.
